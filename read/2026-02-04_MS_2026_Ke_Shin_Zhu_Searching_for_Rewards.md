摘要（中文翻译）：  
忠诚度计划在各类市场中普遍存在，它们通常根据消费者的历史购买行为给予奖励，用于未来的优惠或福利。本文在一个“两期重复的有序搜寻（repeated ordered search）”框架下，刻画忠诚度计划的战略作用及其对竞争的影响：消费者在每一期会在多个企业间顺序搜寻以找到最优产品。研究发现，价格折扣与奖励在影响消费者决策方面扮演截然不同的角色：价格折扣主要抑制当期继续搜寻，而奖励通过让企业在未来一次购买场景中变得“更显眼（prominent）”，从而提升消费者忠诚（使其更倾向于先访问该企业）。当搜寻成本上升时，企业倾向于提供更低的当期折扣、更高的奖励，这会提高行业利润但降低消费者剩余。与不存在忠诚度计划相比，引入忠诚度计划反而会同时降低行业利润与消费者福利，形成“输-输（lose–lose）”结果。进一步地，当企业网络规模（门店覆盖）存在差异时，网络更大的企业往往提供更低的奖励却获得更高的消费者忠诚；网络更小的企业则以更高奖励来弥补其网络劣势。

## 0. 论文速览

本文问的不是“忠诚度计划能不能锁定用户”这种经典问题，而是更具体、更机制化的问题：在一个消费者需要付出搜寻成本、并且未来会再次购买的市场里，企业为什么要做奖励计划？奖励到底通过什么渠道改变竞争？

作者的核心答案是：奖励的关键作用并不仅是（或不主要是）传统意义上的 switching costs（换购成本），而是让企业在未来搜寻中获得 prominence（成为消费者的“默认第一站”）。一旦消费者会先搜寻“我有积分/奖励的那家”，企业就会为了争夺未来的“先被看见”而在当期更激烈地争夺会员，从而把竞争压力前移到第一期。

最应该记住的几件事：

1. 奖励与当期降价是两种不同的武器：降价改变当期“继续搜不搜”，奖励改变未来“先搜谁”。
2. 搜寻成本越高，奖励越高：$r^* = \sqrt{2s}$。直觉是：越难搜到更好的替代品，越值得用奖励把消费者的起始搜寻点固定在自己这里。
3. 忠诚度计划可能导致 prisoner’s dilemma：每家单独看都想给奖励抢 prominence，但均衡结果是行业利润与消费者剩余都更低（输-输）。
4. 网络规模异质时，大网络企业反而倾向于给更低奖励，但忠诚更强；小网络企业“用更高奖励买存在感”，却仍较难赶上大网络的天然覆盖优势。

## 1. 研究背景与动机 (Motivation)

### 1.1 实践痛点：忠诚度计划为何“看起来人人都做，但又总被质疑”？

现实世界里，忠诚度计划几乎无处不在：酒店常旅客、咖啡/快餐积分、信用卡返利、订阅会员点数等。管理者的直觉很简单：奖励能让顾客回来、能提高 CLV（customer lifetime value）。但实践里长期收益高度不确定，常见的抱怨包括：

- 同质化与可复制：竞争对手很快跟进，奖励变成“不得不烧的钱”，难以形成持久差异化。
- 隐性成本：IT 系统、运营、财务负债（未兑换积分）、营销折扣侵蚀利润等。
- 竞争升级：当所有人都在“加码奖励”，行业可能变成零和甚至负和。

这就出现了一个典型管理困惑：忠诚度计划到底是“护城河”，还是“军备竞赛”？

### 1.2 理论缺口：传统 switching-cost 逻辑无法解释的东西

既有文献大量从 switching costs（换购成本）出发：奖励让消费者“离开会痛”，因此企业能提高未来价格、提升利润。问题在于，这套逻辑默认“消费者留在原品牌主要因为效用上被锁定”。

本文强调了一个被忽略的渠道：prominence（在有序搜寻里的显著性/优先访问权）。

- 在有搜寻摩擦的市场里，“先被搜到”本身就有价值：先到的商家可以用价格/匹配来 preempt（截留）需求。
- 奖励计划让“我曾经买过、我有积分”的商家在未来变成消费者自然的第一站，即使消费者最后可能并不买它（这点与纯 switching costs 的“买不买都锁定”不同）。

换句话说，传统模型里“访问=购买”往往被捆绑；本文把“先访问（搜寻顺序）”与“最终购买（效用比较）”拆开，从而能在搜寻模型里定义并研究 prominence。

### 1.3 核心贡献：把“奖励=未来 prominence 的投资”形式化

本文的理论与实践贡献可以压缩成三点：

1. 机制贡献：提出并形式化“奖励通过提高未来搜寻顺序中的 prominence 来竞争”，从而把 loyalty program 的作用与传统 switching-cost 机制区分开。
2. 竞争结果贡献：在该机制下，忠诚度计划可能导致 prisoner’s dilemma：均衡中所有企业都给奖励，但行业利润下降、消费者福利也下降（输-输）。
3. 网络规模贡献：把连锁网络覆盖（activation rate）纳入重复搜寻框架，得到两个对管理很有用的结果：
    - 同质网络下，奖励水平对网络规模不敏感（反直觉）。
    - 异质网络下，大网络企业给更低奖励却更“被优先搜寻”。

## 2. 模型设定与假设 (Model Setup & Assumptions)

### 2.1 符号体系（Symbols）

| 符号               | 含义                                                   | 备注/描述                                                             |
| ------------------ | ------------------------------------------------------ | --------------------------------------------------------------------- |
| $t \in \{1,2\}$    | 时间/购买期                                            | 两期模型，$t=2$可视作未来一次购买并可兑换奖励                         |
| $N \to \infty$     | 企业/品牌数量                                          | 每个城市中存在大量（无穷多）企业，便于求极限与对称均衡                |
| $B$                | 城市数量                                               | 消费者每期随机到一个城市                                              |
| $M$                | 消费者数量                                             | 归一化使得 $M/(N\cdot B)=1$，即“每城市每品牌平均 1 个消费者”          |
| $\gamma \in (0,1]$ | activation rate（网络覆盖率）                          | 每家企业在 $\gamma B$ 个城市有门店/分支；捕捉网络规模                 |
| $\mathcal{B}(j)$   | 企业 $j$ 的活跃城市集合                                | $\mathcal{B}(j) \subset \{1,\dots,B\}$，独立随机实现                  |
| $b(t)$             | 消费者第 $t$ 期到达的城市                              | 在 $\{1,\dots,B\}$ 上随机                                             |
| $v_{jt}$           | 消费者对企业 $j$ 在第 $t$ 期（所在城市分店）的匹配价值 | $v_{jt} \sim \mathrm{Unif}[0,1]$，对 $j$ 与 $t$ 独立                  |
| $s>0$              | 单次搜寻成本                                           | 每多检查一家企业要付出 $s$                                            |
| $p_{jt}$           | 企业 $j$ 在第 $t$ 期的价格                             | 同一企业在同一期对所有城市分店同价                                    |
| $r_j\ge 0$         | 企业 $j$ 的奖励（reward）                              | 只对“第 1 期购买并加入会员”的消费者有效；第 2 期在任一分店可抵扣/返利 |
| $\delta \in (0,1]$ | 折现因子                                               | 消费者与企业都用同一折现（文中用于总利润权重）                        |
| $u_{jt}$           | 消费者在第 $t$ 期从 $j$ 购买的效用                     | 第 2 期若为会员且回购则加上 $r_j$                                     |
| $w$                | reservation value（搜寻保留值）                        | 由 Weitzman(1979) 类型条件确定：继续搜寻的边际收益 = $s$              |
| PBE                | Perfect Bayesian Equilibrium                           | 解概念；对称纯策略均衡是主要关注对象                                  |

### 2.2 博弈/决策结构：Players, Sequence, Information

Players：

- 供给方：$N$ 个企业（品牌），每家在多城市有分店（以 $\gamma$ 表示覆盖）。
- 需求方：大量消费者；每期最多买 1 件。

Sequence of Events（两期）：

1. 企业在 $t=1$ 同时选择当期价格 $p_{j1}$，并承诺奖励 $r_j$（若第 1 期购买，则第 2 期回购可用）。
2. 消费者第 1 期到达随机城市 $b(1)$，进行 sequential search：每访问一家企业需付 $s$，访问后才知道该企业的 $v_{j1}$、价格 $p_{j1}$、奖励 $r_j$。消费者决定是否购买；若购买且 $r_j>0$ 则无成本加入会员。
3. 企业在 $t=2$ 选择价格 $p_{j2}$（允许与第 1 期不同），但奖励承诺在第 1 期已定。
4. 消费者第 2 期到达随机城市 $b(2)$。若其第 1 期购买的企业在该城市“活跃”（概率 $\gamma$），则该企业因为奖励而成为 prominent：消费者会先访问它，再决定是否继续搜寻其他企业。若该企业不活跃（概率 $1-\gamma$），则消费者在活跃企业中随机搜寻。

Information Structure：

- 访问前不知道 $v_{jt}$ 与当期价格；需要搜寻才能发现。
- 关键不对称来自“搜寻顺序”：第 2 期对某个消费者来说，只有其会员企业是 prominent（先被搜寻），其余企业对称。

### 2.3 消费者效用、企业利润与约束

消费者效用：

- 第 1 期购买企业 $j$：$u_{j1}=v_{j1}-p_{j1}$。
- 第 2 期若消费者是 $j$ 的会员且在 $j$ 回购：$u_{j2}=v_{j2}-p_{j2}+r_j$；若不是会员或不回购：$u_{k2}=v_{k2}-p_{k2}$。

可以把奖励理解为“对回购的价格折扣/返利”，但重要的是它同时改变了第 2 期的搜寻顺序（prominence）。

企业利润（边际成本归一化为 0）：

- 第 1 期：$\pi_{j1}=p_{j1}D_{j1}$。
- 第 2 期：会员回购的每单净收入是 $(p_{j2}-r_j)$，非会员（游客）每单净收入是 $p_{j2}$，因此
  $$\pi_{j2}=(p_{j2}-r_j)D^{L}_{j2}+p_{j2}D^{G}_{j2}.$$
- 总利润：$\pi_{jT}=\pi_{j1}+\delta\pi_{j2}$。

约束与可行性：

- 奖励非负：$r_j\ge 0$（允许 $r_j=0$ 表示不做 loyalty program）。
- 消费者每期可选 outside option（不买），其效用归一化为 0；为避免“市场崩溃”，作者给出一段参数区域使消费者仍愿意搜寻并购买。

### 2.4 关键假设与合理性（Justification）

1. 匹配价值独立：$v_{jt}$ 对 $j$ 与 $t$ 独立，且均匀分布在 $[0,1]$。  
   合理性：想捕捉“同一品牌不同城市/不同次购买的体验仍有不确定性”，消费者已知的“品牌共性”可视为搜寻前已内化；搜寻关注的是当次的 idiosyncratic fit（例如酒店位置、房型是否满足当次需求等）。

2. 企业跨城市同价（同一期）：每家企业在同一期对所有分店设同一价格。  
   合理性：大品牌常用全国/全球统一定价策略；同时消费者每期只在一个城市搜寻，跨城市价差对其不显性。

3. 无限企业 $N\to\infty$：使得单个企业偏离不会改变其他企业的需求与策略（近似“垄断竞争”），便于得到解析解与清晰的对称均衡。

4. 有界记忆/注意力的 off-equilibrium belief（Assumption 1）：  
   若消费者第 1 期访问过某企业但未购买，即使看到该企业偏离了均衡的 $p_{j1}$ 或 $r_j$，在第 2 期开始前仍相信该企业第 2 期会按均衡价 $p_2^*$ 定价。  
   合理性与作用：这是为了避免一个“微小降价偏离”通过改变预期而带来“离散的未来搜寻顺序收益”，从而摧毁对称纯策略均衡的存在。直觉上，它等价于：消费者更容易记住自己买过的交易信息，而对只是浏览过但没买的商家记忆很弱。

5. 会员加入无成本：只要 $r_j>0$，购买者都会加入。  
   合理性：现实里加入成本通常很小（扫码/注册）；只要预期收益为正就会加入。模型用此简化来聚焦“奖励改变搜寻顺序”的核心机制。

## 3. 分析与求解 (Analysis & Solution)

### 3.1 核心技术路线：把“搜寻问题”转化为 reservation value 与阈值策略

在标准 sequential search 中，消费者通常采用阈值策略（index policy）：看到当前选项的净效用超过某个阈值就停止搜寻购买，否则继续搜寻。本文沿用该思路，并把阈值（reservation value）显式写出来。

作者先定义第 2 期的 reservation value $w$，用 Weitzman(1979) 的“边际搜寻成本 = 边际期望收益”条件：

$$s=\int_{w}^{1}(v-w)\,dv=\frac{(1-w)^2}{2}\ \Rightarrow\ w=1-\sqrt{2s}.$$

经济直觉：继续多搜一家企业的期望收益来自“若新抽到的匹配价值 $v$ 超过当前保留值 $w$，就获得增量 $v-w$”；把它等于成本 $s$ 就得到停止阈值。

### 3.2 第 2 期：忠诚顾客 vs 游客，两类需求叠加决定最优价格

第 2 期对某个企业 $j$ 来说，需求来自两类人：

- Loyal customers（忠诚顾客）：第 1 期买过 $j$ 并持有其奖励的消费者。
- Guest visitors（游客）：不是 $j$ 的会员，但在搜寻过程中可能会访问到 $j$。

关键是：忠诚顾客会让 $j$ 在第 2 期成为 prominent（第一站），因此 $j$ 面临一群“先看我再说”的顾客，这会显著影响其定价权。

#### 3.2.1 忠诚顾客需求 $D_{j2}^L$

若消费者第 1 期买了 $j$，第 2 期到达的城市里 $j$ 活跃的概率是 $\gamma$。对这些人来说：

- 先访问 $j$（prominence）。
- 访问后观察到 $v_{j2}$，若回购带来的净效用 $v_{j2}-p_{j2}+r_j$ 至少达到“离开去随机搜别家”的保留效用，则购买；否则继续搜寻且不会回头。

因此，忠诚顾客对某一分店的回购需求写成：

$$D_{j2}^L=\gamma D_{j1}\left[1-\left(w-p_2^*+p_{j2}-r_j\right)\right].$$

这里 $D_{j1}$ 是第 1 期该分店吸引到的购买量；括号里是回购的概率（均匀分布下的截断概率）。

直觉：$p_{j2}$ 越高、$r_j$ 越低，回购越少；而 $w$ 越高（搜寻越贵）则消费者更愿意“凑合买”，回购概率更高。

#### 3.2.2 游客需求 $D_{j2}^G$

游客的逻辑更像经典 Wolinsky(1986)：

- 如果游客的会员企业在城市里活跃（概率 $\gamma$），他会先访问会员企业；若该企业的“会员净效用”不够好，则继续随机搜别家。
- 如果会员企业不活跃（概率 $1-\gamma$），他从活跃企业中随机搜寻。

在 $N\to\infty$ 的极限下，作者把“在访问到 $j$ 之前已经搜了多少家”转化为几何级数求和，得到一个非常干净的表达：

$$D_{j2}^G=\frac{\big(\gamma(w-r^*)+1-\gamma\big)\big[1-(w-p_2^*+p_{j2})\big]}{\gamma(1-w)}.$$

直觉上，这里有两个关键因子：

- $\gamma(w-r^*)+1-\gamma$：游客会进入“随机继续搜”的概率权重。$w-r^*$ 代表“访问会员企业后仍不满意而继续搜”的概率。
- $1-(w-p_2^*+p_{j2})$：游客在访问到 $j$ 时决定购买的概率（因为他在 $j$ 没有奖励）。

#### 3.2.3 企业第 2 期最优定价：在“薅忠诚顾客”与“留住游客”之间权衡

第 2 期利润为：

$$\pi_{j2}(p_{j2})=(p_{j2}-r_j)D_{j2}^L+p_{j2}D_{j2}^G.$$

最大化得到最优第 2 期价格 $p_{j2}^*(D_{j1},r_j)$（论文给出闭式解）。作者进一步给出一个很有解释力的改写：最优价格是“只面对忠诚顾客时的最优价”和“只面对游客时的最优价”的加权平均，权重等于“来访者中忠诚顾客的占比”。

经济直觉（对应论文 Lemma 2）：

- 第 1 期吸引的顾客越多（$D_{j1}$ 越大），第 2 期来访的忠诚顾客占比越高，企业更愿意把价格拉向“对忠诚顾客更高的最优价”，因此 $p_{j2}^*$ 随 $D_{j1}$ 上升。
- 奖励 $r_j$ 提高，一方面提高忠诚顾客的有效支付意愿（因为回购时有折扣），企业会抬高标价 $p_{j2}$；但企业对每个忠诚订单要支付更多奖励，净利润会下降，因此最优第 2 期利润随 $r_j$ 上升而下降（“奖励成本效应”压过“需求提升效应”）。

### 3.3 第 1 期：企业用价格与奖励“买”未来的 prominence

第 1 期消费者随机搜寻。访问 $j$ 后观察到 $(v_{j1},p_{j1},r_j)$，消费者会比较：

- 现在就在 $j$ 买，并在第 2 期成为 $j$ 的会员（因此第 2 期先搜 $j$）。
- 继续搜，未来可能成为别家的会员。

作者把这个比较写成一个阈值形式：存在 $\hat v(p_{j1},r_j)$，使得当且仅当 $v_{j1}\ge \hat v$ 时消费者停下来在 $j$ 购买。于是第 1 期分店需求是一个典型的“1 减阈值”形式（再除以城市活跃率项）：

$$D_{j1}=\frac{1-\hat v(p_{j1},r_j)}{\gamma(1-w)}.$$

技术难点在于：消费者对第 2 期的期望要用到企业第 2 期最优定价 $p_{j2}^*(D_{j1},r_j)$，而该最优定价又依赖 $D_{j1}$。作者的处理很聪明：与其直接把 $D_{j1}$ 写成 $(p_{j1},r_j)$ 的复杂函数，不如把 $p_{j1}$ 反过来写成 $(D_{j1},r_j)$ 的显式函数，从而把企业的第 1 期决策等价地看成“选择需求（市场份额）+ 选择奖励”的问题。

### 3.4 核心命题与直觉（Propositions/Theorems + Intuition）

#### 命题 1：存在唯一对称均衡，且均衡中一定有正奖励 $r^*>0$

命题 1 给出一个参数区间（搜寻成本不至于太高）下的唯一对称均衡，并得到闭式解：

- 均衡奖励：
  $$r^*=\sqrt{2s}.$$
- 均衡价格：
  $$p_1^*=\frac{\sqrt{2s}-4\gamma s+2\sqrt{2}(1-2\delta)\gamma^2 s^{3/2}}{\left(1-\gamma\sqrt{2s}\right)^2},\quad p_2^*=\frac{\sqrt{2s}+2\gamma s}{1-\gamma\sqrt{2s}}.$$

直觉（为何一定有 $r^*>0$）：  
如果大家都不提供奖励（$r=0$），第 2 期消费者仍随机搜寻。此时任意一家企业只要提供一个极小的正奖励，就能让“第 1 期买过它的人”在第 2 期先访问它，从而获得离散的需求增量（prominence 带来的“先被看见”）。所以 $r=0$ 不可能是均衡。

直觉（$r^*=\sqrt{2s}$ 为什么这么整齐）：  
$\sqrt{2s}$ 同时也是一个单期 Wolinsky 类型搜寻模型里的对称均衡价格量级。这里奖励的选择被“搜寻阈值结构”强烈约束：奖励要足以让会员企业在第 2 期成为“值得先去看一眼”的选项，而这种“先去看一眼”的价值，恰好由搜寻成本 $s$ 决定。

#### 命题 2：搜寻成本 $s$ 的比较静态——奖励上升、福利下降，但第 1 期价格可能非单调

结论要点：

- $s$ 上升 $\Rightarrow$ $r^*$ 上升，$p_2^*$ 上升，总利润与行业利润上升；消费者剩余与总福利下降。
- $p_1^*$ 对 $s$ 的反应可能是：
  1. 单调上升（当 $\delta$ 小或 $\gamma$ 小，企业更在乎当期利润，搜寻更贵使竞争更软）。
  2. 先升后降（当 $\delta$ 与 $\gamma$ 都足够大：未来很重要且会员企业更可能“在场”）。这时高搜寻成本意味着“锁定并在第 2 期薅利润”更诱人，企业愿意用更低的第 1 期价格去抢会员。

经济直觉：  
把 $p_1$ 理解为“拉新成本/首单优惠”，把 $r$ 理解为“留存激励/积分回馈”。当搜寻成本变高，消费者更不愿意到处比价，回购概率更高，于是企业更想通过奖励强化未来的 prominence；与此同时，企业在第 1 期要不要降价抢会员，取决于“未来利润的重要性”（$\delta$）以及“会员企业在第 2 期真的能出现在消费者城市里”的概率（$\gamma$）。

#### 命题 3：网络覆盖率 $\gamma$ 的比较静态——奖励不变（反直觉），但行业利润下降

结论要点：

- $\gamma$ 上升 $\Rightarrow$ $p_1^*$ 下降，$p_2^*$ 上升，但 $r^*$ 不变。
- 第一、二期利润、总利润、行业利润以及总福利都下降；消费者剩余对 $\gamma$ 的反应取决于 $s$ 的区间，可能先降后升。

最反直觉的一点：$r^*$ 不随网络规模变化。  
作者给的机制解释很干净：在同质网络的情况下，奖励的“作用点”是局部的——它像每个城市分店的回购折扣，决定会员在该城市里是否继续搜别家。网络覆盖率改变的是“会员企业在第 2 期被遇到/被先搜到的频率”，而不是“在某个城市里奖励对停止搜寻的边际效果”。因此均衡奖励不需要随 $\gamma$ 调整；反而价格结构会调整：第 1 期为抢会员更激烈（$p_1^*$ 下降），第 2 期因更强的锁定而更能加价（$p_2^*$ 上升）。

#### 命题 4：有无忠诚度计划的对比——prisoner’s dilemma 与输-输

基准情形（无忠诚度计划）：两期互不相关，均衡价格为
$$p_1^B=p_2^B=\sqrt{2s}.$$

与之相比（有忠诚度计划的均衡）：

- 第 1 期价格更低：$p_1^*<p_1^B$（企业为争夺未来 prominence 而更激烈拉新）。
- 第 2 期标价更高：$p_2^*>p_2^B$（对先来访问的会员企业更有市场力量）。
- 但会员的“有效价格”更低：$p_2^*-r^*<p_2^B$（以奖励形式返利）。
- 总利润与行业利润更低，消费者剩余与总福利也更低。

经济直觉：  
忠诚度计划同时做了两件事：  

1) 它让企业在第 2 期能“更好地薅会员”（高 $p_2$），看似提高利润；  
2) 但它把竞争推回到第 1 期：为了抢到未来的 prominent 位置，企业在第 1 期必须更激进地降价/让利，导致整体利润被竞争消耗掉。最终，(2) 的竞争效应压过了 (1) 的锁定效应，使行业利润下降。与此同时，消费者福利也下降，因为更多购买被“奖励诱导的路径依赖”驱动，而不是匹配效率驱动，导致错配（mismatch）增加。

这就是典型 prisoner’s dilemma：单个企业偏离不做奖励会失去 prominence；但大家都做的均衡反而让所有人更差。

### 3.5 Extension：网络规模异质（Heterogeneous $\gamma$）下的数值均衡

作者把企业分成高类型 $H$（大网络，覆盖率 $\gamma_H$）与低类型 $L$（小网络，覆盖率 $\gamma_L$），高类型占比 $\alpha$。消费者第 1 期访问后才能观察类型。为保持可解性，作者加入 Assumption 2：若第 1 期访问但未购买，则第 2 期不再记得该企业类型，从而第 2 期在非会员企业间随机搜寻。

该 extension 无闭式解，作者用数值分析给出两个核心“Result”。

Result 1（类型比较）：

1. 奖励：$r_H^*<r_L^*$。大网络企业反而给更低奖励。
2. 第 2 期价格：$p_{2H}^*>p_{2L}^*$。大网络企业更能在第 2 期加价。
3. 第 1 期价格：$p_{1H}^*$ 与 $p_{1L}^*$ 的大小取决于参数；当搜寻成本高且网络差距小，大网络企业会更激进地降价抢会员（$p_{1H}^*<p_{1L}^*$），否则可能更高。
4. 需求与利润：$D_{1H}^*>D_{1L}^*$，且 $\pi_{TH}^*>\pi_{TL}^*$。

直觉：  
网络大本身意味着“第 2 期会员企业在场的概率更高”，prominence 更容易兑现为实际访问与购买，所以大网络企业不需要用高奖励去“买忠诚”；小网络企业则必须用更高奖励来弥补“我不一定在你下一次城市里”的劣势。

Result 2（比较静态，摘要式）：

- $\gamma_H$ 上升：高类型奖励下降、低类型奖励上升；两类型第 2 期价格上升；利润下降。
- $\gamma_L$ 上升：两类型策略出现非单调调整（市场结构由“高类型主导”走向“更均衡”）。
- $s$ 上升：与同质情形一致，奖励与第 2 期价格上升，第 1 期价格先升后降，总利润上升但福利下降。

## 4. 主要结论与管理启示 (Main Results & Managerial Insights)

### 4.1 机制揭示：本文相对 benchmark 揭示的新 trade-off

相对“无忠诚度计划”的 benchmark，本文揭示了一个非常清晰的新 trade-off：

- Loyalty program 带来未来优势：通过 prominence 让会员先来访问，企业第 2 期有更强的定价权（$p_2$ 上升）。
- 但也引发当期军备竞赛：为了争夺未来 prominence，企业在第 1 期必须更激烈地让利（$p_1$ 下降），从而把竞争压力前移。

这解释了现实中一个常见的“反直觉”现象：很多行业的会员计划做得越卷，企业反而越累、利润越薄；消费者也未必更开心（因为被引导走向路径依赖，错配增加）。

### 4.2 管理建议：如果你是企业，你该怎么用这篇论文来做决策？

1. 把奖励当作“未来搜寻入口”的投资，而不是只当作折扣。  
   在有明显搜寻摩擦的行业（酒店、旅行、保险、B2B 采购、低频高价品等），消费者的“默认第一站”非常关键。奖励的真正价值可能在于把你变成默认第一站，而不是简单让他回购时少付一点钱。

2. 当搜寻成本下降（比价平台、OTA、聚合搜索、AI 比价助手更强），奖励的战略价值会下降。  
   论文的比较静态指出：$s$ 越低，奖励越低。管理含义是：当外部环境让消费者更容易比较与切换时，单纯堆奖励未必是最有效的 retention 工具，可能要转向其他“减少搜寻/提高匹配”的手段（更好的信息呈现、个性化推荐、服务质量、差异化产品组合等）。

3. 识别并避免 prisoner’s dilemma：行业层面可能需要“克制”。  
   如果你在一个高度对称、竞争者易跟进的市场里，奖励计划很可能把利润推向行业自我伤害。现实做法包括：
    - 用更难被复制的权益（例如服务/体验、合作生态）替代纯货币奖励；
    - 设定差异化规则（门槛、分层、有效期、类别限制）以减少“纯粹比拼奖励强度”的头对头竞争；
    - 在监管允许或行业自律下，避免无限加码（当然要注意反垄断与合规）。

4. 网络规模策略：扩张网络与设计奖励是互补的，但不等价。  
   同质网络下奖励不随 $\gamma$ 变（反直觉），意味着“只靠扩张门店并不能自动减少你需要给的奖励强度”，因为奖励在局部城市层面仍在竞争。  
   异质网络下大网络企业可给更低奖励仍更忠诚，这提示小网络企业的生存策略可能是：
    - 用更高但更精准的奖励做补贴（例如针对高价值场景/城市）；
    - 或者与其他小网络结盟/共享会员体系（相当于提高有效 $\gamma$），把“在场概率”做上去。

### 4.3 Extension 的启示：大网络企业为什么“更抠”却更忠诚？

Result 1 的管理含义非常直接：大网络企业不需要用更高奖励换忠诚，因为它的覆盖率让会员更常遇到它，prominence 更容易兑现。于是它可以把“忠诚收益”转化为更高的第 2 期价格，而不是更高的奖励。

现实对照（论文也举例）：大型连锁通过并购扩张网络后，往往会“收紧”积分权益（奖励变差），但消费者仍难完全离开，因为在更多目的地你更容易遇到它。

## 5. 你的犀利评论 (Reviewer's Critique)

### 5.1 作为 Senior Editor，我会给的正面评价

这篇论文的贡献点很“干净”：

- 机制新：把 loyalty program 与 ordered search 的 prominence 机制结合，明确区分“先访问”与“最终购买”，这是一个在理论上很值钱的拆分。
- 结果锋利：得到输-输与 prisoner’s dilemma，并能用清晰的经济直觉解释“为什么大家都做但不赚钱”。
- 解析度高：同质网络情形有闭式均衡与丰富比较静态；异质网络提供数值分析补充，覆盖了管理者关心的“网络规模差异”问题。

### 5.2 模型限制：哪些假设过强或影响外推？

1. 两期结构与即时兑换过于简化。  
   真实 loyalty program 往往需要累计多次消费才能兑换，且兑换时点不确定。两期模型把“长期积累”压缩成“下一期即可用”，虽然作者在结论里解释其作为隐喻，但这会影响一些动态激励（例如企业是否用延迟兑换来降低竞争强度、消费者是否因不确定性而折现更强）。

2. 消费者只持有一个“代表性会员关系”的抽象。  
   现实中消费者常同时持有多个会员计划。多重会员会让第 2 期的 prominence 不再是“一家独大”，而可能变成一个“会员集合的有序搜寻”（先搜 A 再搜 B）。这可能削弱 prisoner’s dilemma 或改变其形态。

3. Off-equilibrium belief（Assumption 1）在理论上必要，但也最容易被挑剔。  
   它引入了有界记忆以保证对称纯策略均衡存在。虽然直觉合理（人更记得交易而不是浏览），但它仍然是一个“为了解析解而做的强设定”。读者可能会问：如果消费者有更强记忆/更复杂推断，会不会出现混合策略或非对称均衡？结论是否稳健？

4. $N\to\infty$ 与均匀分布带来的简化。  
   这些假设让需求表达很漂亮，但也意味着模型更像“垄断竞争极限”，而不是典型寡头竞争。实际很多 loyalty program 竞争发生在寡头或平台环境（航空、酒店、外卖平台、信用卡），那里的策略互动可能更尖锐（例如互相定向挖角、匹配/搜索算法等）。

5. 企业在每期跨城市同价，且不允许个性化。  
   实务上 loyalty program 往往与个性化定价/定向优惠绑定。若允许对会员与非会员分别定价（或更细的行为定价），prominence 与 BBP（behavior-based pricing）之间会产生更复杂的相互作用。

### 5.3 未来方向：在这篇基础上可以写哪些“有希望中顶刊”的扩展？

1. 多期模型 + 积分门槛/有效期：  
   研究奖励设计（阈值、过期）是否能在一定程度上缓解 prisoner’s dilemma（例如通过制造“奖励的稀缺性”来减少 head-to-head 比拼）。

2. 重叠会员与“多 prominent”搜寻：  
   让消费者同时持有 $K\ge 2$ 个会员身份，搜寻顺序可能是“先搜最常用/最可能在场的那个”，再搜第二个……这会把 prominence 从二元变成序位竞争。

3. 内生网络规模：$\gamma$ 由企业投资/并购决定。  
   目前 $\gamma$ 是外生。一个自然的扩展是：企业在奖励竞争与网络扩张之间做联合决策（投资提高 $\gamma$，降低需要给的奖励）。这能把论文的 Marriott/SPG 叙事变成可检验的理论命题。

4. 数据与实证检验：  
   可以用平台数据或企业 CRM 数据检验“prominence”渠道：奖励提升是否主要体现在消费者下一次访问顺序/点击顺序，而不只是回购概率？例如 OTA 搜索日志、App 首次打开的品牌顺序、收藏/默认排序等。

5. 平台与排序算法：  
   若搜索顺序由平台排序算法决定（付费排名、个性化推荐），企业可以“买 prominence”。把 loyalty rewards 与 paid prominence 放在同一模型里，会非常贴合当下的数字市场现实。

## 6. One More Thing

本文最值得分享的“灵光一现”是：忠诚度计划的核心不一定是让消费者“换品牌会痛”，而是让消费者“下一次先想到你、先搜到你”。

在有搜寻摩擦的世界里，第一站就是一块战略高地。奖励把这种高地私有化到每个消费者身上：对我而言，你成了默认第一站；对另一个消费者而言，可能是另一个品牌。于是竞争从“谁给更好的产品/价格”扩展为“谁能成为更多人的第一站”，并因此产生一种很现实的军备竞赛逻辑：大家都在为 prominence 付费，但最终谁也没捞到好处——甚至连消费者都没捞到。
