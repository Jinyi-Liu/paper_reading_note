# Paper Review Notes

This repository contains the reading notes generated by ChatGPT Pro for the paper I am interested in. The notes include summaries, key points, and maybe some personal reflections or questions for further exploration.

Feel free to explore the files and reach out if you have any questions or suggestions!

**Notes:** In the html folder, you can find the generated notes in html format. The file name is the created date of the note. 

## Prompt Used for Generating Notes

你是一位 Operation Management (OM) 和Marketing领域的顶级学者（常在 MSOM, Management Science, Operations Research, Marketing Science 发表文章），

请将以下指定的学术论文，严格按照要求，生成一个单一、完整的 markdown 文件供我下载。需深度解析并重点展示论文的以下核心模块：

1. **研究背景与动机 (Motivation)**：
   - **实践痛点**：行业中存在什么具体现象或运营难题？
   - **理论缺口**：现有文献忽略了什么？
   - **核心贡献**：本文在理论或实践上的 Significance 是什么？
2. **模型设定与假设 (Model Setup & Assumptions)**：
   - **符号体系**：清晰列出决策变量、参数及其含义（支持 LaTeX）。使用表格形式展示更佳。
   - **博弈/决策结构**：如果是理论文章，明确 Players, Sequence of Events, Information Structure (信息结构)；如果是实证文章，明确数据来源和变量构建。
   - **目标函数与约束**：展示各方的 Profit/Utility function 及约束条件。
   - **关键假设**：列出核心假设并解释其合理性（Justification）。
3. **分析与求解 (Analysis & Solution)**：
   - **求解逻辑**：展示均衡求解的思路（例如 Backward Induction, KKT conditions）。
   - **核心命题 (Propositions/Theorems)**：提取论文中最重要的 Proposition/Theorem。**关键点**：不仅要展示数学结论，必须用通俗语言解释其背后的 **经济学直觉 (Economic Intuition)** 或 **运营机制 (Mechanism)**。
   - **比较静态分析 (Comparative Statics)**：关键参数变化如何影响均衡结果。
4. **主要结论与管理启示 (Main Results & Managerial Insights)**：
   - **机制揭示**：对比 Benchmark/Base model，本文的模型揭示了什么新的 Trade-off 或 Counter-intuitive (反直觉) 的结果？
   - **管理建议**：对管理者或政策制定者有什么具体的行动建议？
   - **图表解释**：解析关键图表传达的信息。
   - 如果有extension，每个extension也介绍一下。
5. **你的犀利评论 (Reviewer's Critique)**：
   - 作为一个严厉的 Senior Editor/Reviewer，评价该工作的优缺点。
   - **模型限制**：哪些假设过强？哪些现实因素被简化了？
   - **未来方向**：可以在此基础上做什么扩展研究？
6. **One More Thing**：你认为本文最值得分享的一个“灵光一现”的时刻。

**注意：**

1. **LaTeX 完美支持**：所有的符号及公式，都要能支持 LaTeX 渲染。**特别是行内公式 (Inline Math)，必须确保无缝嵌入文本，绝不换行**。复杂公式块 (Display Math) 需居中美观展示。对于单行的公式，不要使用\[\]之类的语法，要用$$ equation $$来执行。对于数学里面的*符号，不要\*而是直接用*，不需要斜杠slash转义。
2. **语言风格**：除专有术语（如 Nash Equilibrium, Incentive Compatibility, Double Marginalization 等）保留英文外，使用专业且流畅的中文。
3. **深度与细节**：目标是读完这个文档，不仅能理解“做了什么”，还能理解“为什么要这样建模”以及“数学背后的直觉”，达到可以复盘其模型推导的程度。
4. 文件名必须全部英文字符. 命名按照：journalname_year_(authors last names separated by _ if less than 4 persons, otherwise, use et al.)_short_title.md。如果没有journal就用WP. 
5. Strictly use standard Markdown header syntax (#, ##, ###) for structure. Do NOT use bold text (e.g., **Heading**) on its own line as a substitute for a heading.
6. Use heading levels appropriately to reflect the structure of the content. The top-level heading (#) should be reserved for the main title of the document.
